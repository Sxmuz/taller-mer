# Taller MER

Aplicación web para **practicar el Modelo Entidad-Relación (MER)** y el **paso a tablas** (modelo relacional), pensada para alumnos de Bases de Datos de FP (DAM, DAW, ASIR) y de primeros cursos de universidad.

Es un único archivo HTML: no necesita instalación, servidor ni cuenta. Ábrelo en el navegador y empieza a practicar.

## Qué puedes hacer

- **Subrayar el enunciado** con rotuladores de colores (entidad, relación, atributo) y pasar las palabras al diagrama con doble clic.
- **Dibujar el diagrama E-R**: entidades, entidades débiles, relaciones (también reflexivas y ternarias), relaciones débiles, atributos (clave, discriminante, multivalorado), generalizaciones ISA y cardinalidades (mín,máx).
- **Comprobar** el diagrama contra la solución y ver qué falla y por qué. También puedes ver el diagrama corregido encima del tuyo.
- **Paso a paso**: si te atascas, te dice qué hacer a continuación.
- **Pasar a tablas** (modo 📋 Tablas): escribe el esquema relacional con claves primarias y ajenas, y se corrige.
- **Estudiar** (menú ☰): teoría del MER, lecciones de paso a tablas, chuleta, test de teoría y un repaso de tus errores más frecuentes.
- **Modo examen**: ejercicio al azar con tiempo y sin ayudas.
- **Descargar** tu diagrama en PNG o SVG y guardar o cargar una copia de tu progreso.

El progreso se guarda en el propio navegador (`localStorage`).

## Ejercicios

Incluye 10 ejercicios por niveles (fácil, medio, difícil y examen), cada uno con pistas, solución dibujada, explicación y su paso a tablas.

## Cómo usarlo

1. Descarga `index.html` (o clona el repositorio).
2. Ábrelo con cualquier navegador moderno (Chrome, Edge, Firefox).

También se puede publicar tal cual con GitHub Pages.

> El botón «Preguntar a Claude» solo funciona cuando la app se abre como artefacto en claude.ai. En el resto de casos se oculta y todo lo demás funciona igual.
